# **App Name**: PitchPulse

## Core Features:

- Dynamic Delivery Generator: Trigger random cricket outcomes including runs, various extras, and all legal dismissal types with a single click or keyboard interaction.
- Real-time Scorecard Engine: Tracks complex metrics for both the active batter and the full innings, managing overs, strike rates, and extras in real-time.
- Simulation Over-Drive: Automatically generates a complete set of six legal deliveries at once, summarizing the impact on the scorecard immediately.
- Custom Probability Controls: Allows users to adjust the weighting and visibility of specific outcomes like wickets or boundaries through an interactive settings panel.
- Wicket Alert Visuals: High-impact visual animations and color-shifting alerts triggered immediately upon dismissal results to create excitement.
- Offline PWA Capability: Provides full app functionality and scorecard persistence even without an active internet connection.

## Style Guidelines:

- Primary color is a vibrant Turf Green (#19e681) to represent the field, contrasted against a deep Midnight Green background (#141f1a) for a high-end dark-mode aesthetic.
- Accent color is a Bright Lime (#b6f279), used strategically for critical game actions, stats, and call-to-action buttons.
- Headlines and scores use "Space Grotesk" (sans-serif) for a modern, tech-forward feel. For readability in statistical tables, "Inter" (sans-serif) is used as the primary body font.
- Minimalist outline icons representing balls, stumps, and cricket bats, ensuring high contrast against the dark background.
- A centralized hero display focusing on the latest ball outcome, surrounded by modular statistics cards for player and innings totals.
- Reactive micro-animations for numbers on the scorecard and a red strobe flash effect when an "OUT" outcome is triggered.
